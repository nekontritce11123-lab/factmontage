# FactMontage 1.2

[English](RELEASE_NOTES.md) · [На главную](../README_RU.md)

**Статус: подготовка выпуска. Стабильная публикация ожидает приёмку.**

Основа кандидата: исходники VideoStudio **1.2-rc13**, коммит `c219211a9b069abbf205184195727dd3f024dddc`. Перед изменениями сверены все 603 файла сохранённого состава сборки.

Подготовка включает отображаемое название FactMontage, значок FM, пользовательскую документацию EN/RU и отдельный репозиторий исходников. Идентификатор Flatpak, ID эффектов, ABI и сигнатуры ресурсов сохранены. Исправлена проверка путей Windows во вспомогательном тесте рабочего цикла.

Предыдущий rc13 прошёл автоматическую цепочку и был установлен и запущен на Steam Deck. Эти результаты не принимают переименованный кандидат. Новый пакет требует собственных проверок, контрольных сумм и записи исходников.

Для выпуска нужны FAST, интеграция с редактором, SMOKE, сборка из публичной копии исходников, монтажные сценарии и экспорт, установка/обновление/откат и физическая приёмка Steam Deck. Итоговый пакет должен соответствовать тегу исходников и протоколам проверок.
