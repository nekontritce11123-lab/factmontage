# Publication demo project

The GitHub screenshots must be captured from the renamed FactMontage candidate in a real dark Kdenlive workspace. One project supplies the monitor, timeline and examples for all eight sections.

Only redistributable materials are permitted. Demo graphics, tones and title text are created for this project. Any external human footage used to demonstrate segmentation or tracking must have a recorded source URL and licence in `SOURCES.json`.

The demo must show applied results. Panel-only layout captures and earlier release screenshots are not publication images. Private editing or QA footage is excluded.

Source generators and the project file belong here. Generated video and large assets are distributed with the demo release materials, outside the Git source tree.
