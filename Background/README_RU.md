# Background — движок раздела «Фон»

Изолированный движок общей панели «Монтажная студия». Публичный MLT-сервис —
`studio.background`; XML скрыт из обычного списка эффектов Kdenlive.

## Режимы

- **Однотонный фон**: медианная пипетка 7×7, допуск, мягкость и подавление
  цветного отсвета. Предварительный анализ не нужен.
- **Человек**: заранее рассчитанная PP-HumanSegV2-Lite-маска `.sbg`. Во время воспроизведения и
  экспорта нейросеть не запускается.
- Результат: прозрачность, размытие исходного фона или однотонная заливка.

Первая версия не содержит кистей, инверсии, показа/экспорта маски, выбора
отдельного человека, live-камеры, HDR, GPU и загрузчика нового фона. Картинка
или видео для замены фона остаётся обычным нижним слоем Kdenlive.

## Структура

```text
scripts/generate_ui.py            единственный источник параметров
include/ и src/                   ядро, формат .sbg, PNG и SHA256
mlt/filter_background.cpp         MLT-фильтр studio.background
bin/analyze.cpp                   отдельный CPU-анализатор PP-HumanSegV2-Lite
kdenlive/                         сгенерированные XML и JSON v2
tests/                            контракт, ядро, кэш и CLI
models/README_RU.md               правила закрепления модели
```

Сохраняемое свойство `mask_asset` содержит только относительное имя файла в
`CacheBase/studio-background`. Абсолютный путь передаётся фильтру во внутреннем
несериализуемом свойстве `_sbg_mask_path`. Исходный клип, рецепт анализа, FPS и
диапазон проверяются перед чтением; ошибка маски не должна тихо раскрывать фон.

## Сборка модуля без Kdenlive

```bash
cmake -S Background -B Background/build -G Ninja
cmake --build Background/build
ctest --test-dir Background/build --output-on-failure
```

`SBG_WITH_MLT=ON` требует официальные заголовки MLT 7. `SBG_WITH_ONNX=ON`
требует закреплённый ONNX Runtime 1.21.0; путь передаётся через
`ONNXRUNTIME_ROOT`. Анализатор принимает последовательный поток RGBA8888 из
клона MLT-producer, работает в 1–2 CPU-потока и публикует `.sbg` только после
полной записи и проверки.

Модель `pp_humansegv2_lite_portrait_static.onnx` экспортируется из официальных
весов через `scripts/export_humanseg_onnx.py` вне дерева исходников. При
подготовке Flatpak передайте путь через `STUDIO_HUMANSEG_ONNX`; манифест и
анализатор проверяют SHA256. Текст лицензии включён в пакет. Сетевых загрузок
при работе пользователя нет. Замена остаётся экспериментальной до приёмки на Deck.

Это часть неофициальной экспериментальной сборки и не выпуск KDE/Kdenlive.
