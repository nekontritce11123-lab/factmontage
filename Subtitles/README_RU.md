# Субтитры монтажной студии

Контракт раздела находится в `scripts/generate_ui.py`. Сгенерированные
`generated/parameters.json` и `generated/subtitle_parameters.hpp` не редактируются вручную.

Первая версия работает локально, распознаёт русскую речь через `whisper.cpp`,
сохраняет временные метки слов и экспортирует только запечённый рендер. Внутри
проекта используется один управляемый ASS-трек.

Нативный worker `studio-subtitle` принимает WAV, локальные модели Whisper и Silero VAD
(`--model` и `--vad-model`) и путь к `whisper-cli`. Детектор речи отсекает неречевой
звук до распознавания; без модели VAD или речи результат не публикуется. VAD может
ошибаться на сложном звуке, поэтому результат всё равно требует проверки.
Worker публикует рядом с кэшем `words.json`, `blocks.json` и ASS-файл.
Сырой результат распознавания кэшируется по хешам аудио и обеих моделей; смена оформления
не запускает ASR заново. Итоговый ASS дополнительно зависит от версии контракта,
области и оформления. Повреждённый или незавершённый результат не берётся из кэша.
Старый кэш без VAD не используется. Закреплённый CLI содержит маленькую правку
JSON, сохраняющую исходные временные метки слов после VAD; worker проверяет этот
контракт и исходные интервалы речи. Слово на стыке двух интервалов ограничивается
одной подтверждённой речевой областью; строки не растягиваются через удалённую паузу.
Предпросмотр и переоформление готовых блоков не требуют моделей ASR/VAD.
Разделение и объединение блоков сохраняет стабильный ID первого блока и повторно
рассчитывает переносы строк.

В панели доступна только длина строки. Каждая фраза выводится строго одной строкой
на тёмной плашке; длительность, размер, обводка и отступы задаются автоматически.
После анализа нужно проверить редкие слова и тайминги на редактируемой дорожке:
модель распознавания может ошибаться даже при правильной раскладке.
Если метки речи пересекаются, первый блок остаётся видимым до конца речи, следующий
сдвигается; панель сообщает число конфликтных блоков для ручной правки. В
`blocks.json` сохраняются исходный конец речи и признак конфликта.

Основной пользовательский материал для приёмки хранится вне репозитория:
`VID_20260913_0037194020003-30fps.mp4`, SHA-256
`23D28947B29AF859E1B68F7AFD268EAA945D9F52B78F0E705D4EA1A0F802B3BC`.
Файл не копируется в Git из-за размера; тестовый запуск принимает его путь явно.

Проверки:

```sh
python3 scripts/generate_ui.py --check
python3 tests/test_contract.py
```

Нативная проверка выполняется в Linux/Flatpak SDK:

```sh
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build
ctest --test-dir build --output-on-failure
```
