# Card 3D

Один эффект Kdenlive для карточек: готовое оформление, появление и плавная перспектива.
Цель — Steam Deck OLED / SteamOS / Kdenlive Flatpak `org.kde.kdenlive`.

**Текущий статус: Card 3D собран и проверен в Linux WSL2. Встроенная панель
единой студии и её Flatpak ещё не прошли приёмку. Установочного релиза нет.**
Актуальные результаты и оставшиеся проверки: [единый отчёт](../docs/RELEASE_NOTES_RU.md).

## Как пользоваться

Добавьте изображение или видео на дорожку выше фона. Найдите **Card 3D** среди
эффектов и добавьте один экземпляр. Выберите вид и расположение — остальное уже настроено.
После входа карточка по умолчанию спокойно движется. Для неподвижной карточки
выберите «Без движения». Для задержки появления передвиньте начало клипа на таймлайне.

| Настройка | Что выбирает пользователь | По умолчанию |
|---|---|---|
| Вид карточки | Панель / Бумага / Фото | Панель |
| Появление | Без появления / Мягкий выезд / Выезд с вытягиванием / Из глубины / Раскрытие | Мягкий выезд |
| Откуда | Один из четырёх углов | Слева снизу |
| Расположение | Центр, слева, справа или один из четырёх углов | Слева |
| Размер | 15–100% доступной области; пропорции сохраняются | 68% |
| Длительность появления | 0,25–2,5 секунды | 0,85 с |
| Движение | Без движения / Спокойное / Живое | Спокойное |
| Источник | Изображение / Видео | Изображение |

**Панель** — скругление и тонкая окантовка. **Бумага** — светлая рамка и рваный
край. **Фото** — прямые углы и белая рамка. Тень и торец настроены внутри каждого
пресета. Смена вида сохраняет расположение, размер и появление.

Для PNG с прозрачными полями выбирайте «Изображение». Для видео и анимаций с
меняющейся прозрачностью — «Видео»: границы карточки останутся стабильными.
Встроенные чёрные поля не вырезаются. Прозрачные участки внутри карточки заполняются
подложкой пресета. «Откуда» и «Длительность» не используются при «Без появления».
«Без движения» отключает перспективное движение после входа, само появление сохраняется.

## Установка готового Linux-пакета

Этот раздел применяется **после получения проверенного архива** с `bin/linux-x86_64/card3d.so`.
Установите Kdenlive Flatpak из Discover, сохраните проект и закройте редактор.
Распакуйте весь архив, откройте терминал в его папке и выполните:

```bash
bash INSTALL.sh
```

Компиляция на Deck и sudo не нужны. Установщик использует системный Python 3,
сохраняет чужие плагины и пути, проверяет загрузчик MLT, если в Flatpak есть `melt`.
После установки запустите Kdenlive и найдите **Card 3D**.

```bash
bash CHECK.sh
bash UNINSTALL.sh
```

При другой версии файлов сначала удалите прежнюю установку через её UNINSTALL.sh.
Изменённые пользователем файлы автоматически не удаляются. Проверка доступности
файлов без melt не доказывает загрузку эффекта. Права Flatpak и системный раздел
SteamOS установщик не изменяет. Совместимость со старой экспериментальной версией не предусмотрена.

## Разработка в WSL2

Корневой `../AGENTS.md` содержит правила всей рабочей папки. WSL2 Ubuntu-24.04
уже установлена. Для новой машины установка в PowerShell:

```powershell
wsl --install -d Ubuntu-24.04
```

Завершите первый запуск Ubuntu и создание обычного Linux-пользователя. В Ubuntu:

```bash
sudo apt-get update
sudo apt-get install -y build-essential cmake frei0r-plugins-dev melt ffmpeg python3-numpy python3-pil fonts-dejavu-core
# Сначала скопируйте исходники на внутренний Linux-диск.
cd ~/video-studio/Card_3D
bash scripts/check-linux.sh
```

Проверки включают настоящий Linux-рендерер, независимый хост с системным Frei0r
заголовком, ASan/UBSan, установщик с моделью Flatpak и реальный системный MLT.
Они **не заменяют Kdenlive Flatpak и проверку на Deck**.
При изменении списка параметров сначала запускайте `python3 scripts/generate_ui.py`.

Проверки, обновлённая демонстрация, замер скорости, контрольные суммы и архив:

```bash
bash scripts/package-linux.sh
```

При ошибке любого обязательного теста упаковка прекращается. Выходной архив:
`build/Card_3D_linux_x86_64.tar.gz`. Не добавляйте в него старый .so.
Перед распространением выполните сценарии Deck из отчёта и зафиксируйте точные версии.

## Дополнительные проверки Windows

Нужны Visual Studio Build Tools с C++ x64 и Python с NumPy/Pillow.
Windows DLL используется исключительно для проверки алгоритма; она не устанавливается на SteamOS.

```powershell
./scripts/check-windows.ps1 -Python 'путь/к/python.exe'
python tests/render_showcase.py --preview-only
```

Независимый ABI-хост дополнительно использует официальный `frei0r.h` в `build/abi`.
Использован заголовок Frei0r v2.3.3; ссылка и SHA256 указаны в отчёте.
Предпросмотр сохраняется в `build/native/preview`: это рендер DLL, не снимок Kdenlive.
