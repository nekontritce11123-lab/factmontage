# Studio FX

Один Frei0r-обработчик `frei0r.studiofx` для раздела «Эффекты» монтажной студии.
80 пользовательских шаблонов описаны в `scripts/generate_ui.py`; сгенерированные
заголовок, каталог и XML вручную не редактируются.

Короткая проверка без сборки Kdenlive:

```sh
python3 scripts/generate_ui.py --check
python3 tests/test_contract.py
```

Поставляемая библиотека собирается внутри закреплённого Flatpak SDK. Приложенный
к исходным материалам экспериментальный бинарник не используется.
