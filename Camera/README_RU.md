# Камера монтажной студии

Нативный MLT-фильтр `studio.camera` для общей панели Kdenlive. Он поддерживает
живой дрейф, плавное приближение, отдаление, приближение с возвратом, циклический
зум, проезд между двумя точками и заранее рассчитанное слежение за головой.

Пользователь выбирает тринадцать понятных настроек. По умолчанию движение занимает
весь клип; заданное время доступно как дополнительный режим. При разрезании
скрытые `studio_time_origin` и `studio_time_span` сохраняют исходную траекторию.

Для трекинга пользователь обводит голову рамкой в мониторе клипа. Нативный
`studio-head-tracker` один раз анализирует выбранный отрезок через OpenCV CSRT и
атомарно сохраняет координаты в `.scam`; движок читает этот файл при просмотре и
экспорте. Можно выбрать и ранее созданный `.scam`. Браузерный сервер не используется.
Исходная Camera Studio 1.0 со всеми материалами сохранена без изменений в `../archive`.

## Проверка в Linux

Запускайте на Linux-диске WSL2, где установлены CMake, Ninja, GCC, Python,
FFmpeg, MLT и заголовки `mlt-framework-7`:

```bash
bash scripts/check-linux.sh
```

Сценарий проверяет сгенерированный контракт, движок, ASan/UBSan, обнаружение
фильтра настоящим MLT и полное совпадение 30 кадров до и после модельного
разрезания клипа. GUI Kdenlive, Flatpak и Steam Deck проверяются отдельно;
актуальный статус находится в [едином отчёте](../docs/TEST_REPORT_RU.md).
