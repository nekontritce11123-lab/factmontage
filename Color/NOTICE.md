# Авторство и лицензирование

Исходники Studio Color в этом пакете подготовлены специально по заданию пользователя
с помощью ChatGPT. Лицензия новых исходников: GPL-3.0-or-later; полный текст GPLv3
в LICENSE. Пакет не является официальным выпуском KDE, Kdenlive, MLT или OpenAI.

Официальные публичные API Kdenlive/MLT и документация других проектов использованы
как справочные материалы. Сторонние реализации LUT, color-matcher, OCIO, zimg,
libplacebo, OpenCV не скопированы и не поставляются. Названия библиотек принадлежат
соответствующим авторам. MLT — отдельная системная/Flatpak-зависимость; её лицензионные
уведомления сохраняются при поставке всей студии. Не менять уведомления уже имеющегося
исходного проекта.

Восемь .cube сгенерированы собственной аналитической функцией пакета, не скопированы
из платных LUT-наборов. Они не имитируют конкретный коммерческий продукт или плёнку.
Название SUNIMO использовано как пользовательский вариант умеренно тёплого стиля,
а не гарантия точного воспроизведения брендовых/товарных цветов.
